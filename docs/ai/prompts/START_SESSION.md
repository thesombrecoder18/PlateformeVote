# START_SESSION.md

## Contexte minimal pour demarrer

Lire dans cet ordre :
1. AGENTS.md
2. STATUS.md
3. NEXT_SESSION.md
4. docs/roadmap/sprints/<sprint_actif>.md

## Actions initiales

- Identifier le sprint actif dans STATUS.md
- Lire la feature doc concernee
- Verifier les tests : pnpm test
- Verifier TypeScript : pnpm typecheck

## Ne pas

- Lire tout le depot
- Refaire des fichiers deja crees
- Changer de stack sans justification ADR
