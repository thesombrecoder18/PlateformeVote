# RETENTION_AND_DELETION.md

## Politique de conservation par categorie

### Comptes et profils
Conservation : duree de la relation + 5 ans (a definir avec conseil)
Suppression : desactivation du compte, puis suppression differee

### Donnees electorales (resultats publics)
Conservation : permanente (ou selon reglement de l organisation)
Anonymisation : possible apres delai defini

### Listes electorales
Conservation : duree du scrutin + periode legale contestation
Acces : restreint apres archivage du scrutin

### Journaux d audit
Conservation : minimum 5 ans (a confirmer selon loi)
Suppression : jamais de suppression sans procedure documentee

### Fichiers justificatifs
Conservation : duree instruction + 2 ans
Acces : journalise, restreint
Suppression : apres expiration, selon politique organisation

### Donnees de communication (emails)
Conservation : 1 an (logs) / 3 ans (templates)

## Droits des personnes

- Acces : interface dans le backoffice (a implementer)
- Rectification : selon le type de donnee et le contexte electoral
- Suppression : selon retention policy et obligations legales

## Statut

A definir et valider avec conseil juridique avant traitement reel.
